Troubleshooting Guide:
Common Issues and Solutions:

1. Can't connect to MySQL server remotely:
bash# Check if MySQL is listening on all interfaces
sudo netstat -tlnp | grep 3306

# Should show 0.0.0.0:3306 not 127.0.0.1:3306
# If not, edit MySQL config and restart

2. Access denied for user:
sql-- Run as root on server
SHOW GRANTS FOR 'username'@'%';
GRANT ALL PRIVILEGES ON mobility_bot_server.* TO 'username'@'%';
FLUSH PRIVILEGES;

3. Firewall blocking connection:
bash# Linux
sudo ufw status
sudo ufw allow from YOUR_IP to any port 3306

# Windows
netsh advfirewall firewall show rule name="MySQL Server"

4. Application still using local database:
bash# Check current config
python -c "from dotenv import load_dotenv; import os; load_dotenv(); print(f'DB_HOST: {os.getenv(\"DB_HOST\")}'); print(f'DB_NAME: {os.getenv(\"DB_NAME\")}')"

# Switch to server config
python config_manager.py  # Choose option 1
